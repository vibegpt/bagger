## Reddit Strategy

### ⚠️ Critical Rules

**NEVER:**
- Lead with "Check out my tool"
- Post the same link across multiple subreddits
- Be obviously promotional
- Skip the community participation phase

**ALWAYS:**
- Provide value first
- Build karma before mentioning Bagger
- Only mention when directly asked
- Share data/insights, not ads

### Phase 1: Lurk & Learn (Weeks 1-2)

**Actions:**
- Subscribe to target subreddits
- Read rules and pinned posts
- Observe what gets upvoted/downvoted
- Note posting patterns and culture

### Phase 2: Participate & Build Karma (Weeks 3-6)

**Actions:**
- Comment on discussions (10-15 comments/week)
- Answer questions genuinely
- Share insights WITHOUT mentioning Bagger
- Build reputation as knowledgeable member

**Example Good Comments:**
- "Interesting finding: Top 10 holders of $TOKEN increased positions 30% this week"
- "The graduation rate has been dropping - went from 1.7% to 0.7% in just two weeks"
- "I've been tracking this, and whales are accumulating during these dips"

### Phase 3: Subtle Integration (Weeks 7+)

**When Someone Asks:**
- "What tools do you use?" → "I've been using Bagger for tracking Pump.fun and Zora"
- "How do you track this?" → "There are a few tools, I use Bagger because it covers both chains"

**Educational Posts (Monthly):**
- "Understanding Raydium Graduation Rates [Data Analysis]"
- "I analyzed 10,000 Pump.fun launches. Here's what I found..."
- Add at the very end: "Data collected using Bagger analytics"

### Target Subreddits

#### High Priority

**r/CryptoCurrency** (5.9M members)
- **Rules:** VERY strict anti-promotion, earn "Moons" for quality posts
- **Strategy:** Share data insights only, mention tools when asked
- **Posting:** Max 1x/month educational post
- **Commenting:** 3-5x/week on trending topics

**r/solana** (Active Solana community)
- **Rules:** More lenient, tech-focused
- **Strategy:** Pump.fun data analysis, technical discussions
- **Posting:** 1x/2 weeks with data insights
- **Commenting:** Daily on Pump.fun discussions

**r/CryptoMoonShots** (Meme coin focused)
- **Rules:** Moderate, loves data
- **Strategy:** Token launch analysis, early signals
- **Posting:** 2x/month "Here's what the data shows..."
- **Commenting:** 2-3x/week on new launches

**r/web3** (30K members, developer-focused)
- **Rules:** Lenient, appreciates tools
- **Strategy:** Creator economy insights, technical posts
- **Posting:** 1x/month creator economy analysis
- **Commenting:** Weekly on relevant threads

#### Medium Priority

**r/NFT** - Zora creator coin discussions
**r/defi** - When people ask for portfolio trackers
**r/ethdev** & **r/ethereum** - Technical Zora/Base discussions

### Reddit Don'ts

**Will Get You Banned:**
- Posting same content to 5+ subreddits
- Brand new account immediately promoting
- Obvious affiliate links
- Responding to every tracker question with Bagger
- Arguing with moderators

**Better Alternatives:**
- Participate for 4+ weeks first
- Share insights, let people ask about tools
- Mention 2-3 tools when asked (including Bagger)
- Accept feedback gracefully

### Data Storage Schema

```sql
CREATE TABLE weekly_reports (
  id SERIAL PRIMARY KEY,
  week_number INTEGER,
  report_date TIMESTAMP,

  -- Zora metrics
  zora_total_creators INTEGER,
  zora_total_traders INTEGER,
  zora_trading_volume DECIMAL,
  zora_creator_earnings DECIMAL,
  zora_daily_coins INTEGER,
  zora_whale_increase DECIMAL,

  -- Pump.fun metrics
  pump_daily_launches INTEGER,
  pump_graduation_rate DECIMAL,
  pump_daily_graduations INTEGER,
  pump_daily_users INTEGER,

  -- Generated content
  twitter_thread JSONB,
  insights JSONB,

  -- Status
  posted BOOLEAN DEFAULT false,
  posted_at TIMESTAMP,

  created_at TIMESTAMP DEFAULT NOW()
);

-- Index for querying trends
CREATE INDEX idx_week_number ON weekly_reports(week_number);
CREATE INDEX idx_report_date ON weekly_reports(report_date);
```
